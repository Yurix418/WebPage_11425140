bit888 機構與量化 API 串接指南

平台提供機構級低延遲 REST API 及實時 WebSocket 撮合流，支援高頻造市商、量化對沖策略與演算法程式化下單。

REST 端點: https://api.bit888.com/v1
WebSocket 串流: wss://stream.bit888.com/ws
頻率限制: 10,000 requests / min
Python 程式化下單範例程式碼:
import hmac, hashlib, time, requests

API_KEY = "bit888_algo_live_key_9981"
SECRET = b"bit888_secret_signature_token"

def place_order(symbol, side, price, amount):
    timestamp = str(int(time.time() * 1000))
    payload = f"{timestamp}POST/v1/order{symbol}{side}{price}{amount}"
    signature = hmac.new(SECRET, payload.encode(), hashlib.sha256).hexdigest()
    
    headers = {
        "X-BIT-APIKEY": API_KEY,
        "X-BIT-SIGNATURE": signature,
        "X-BIT-TIMESTAMP": timestamp
    }
    # 傳送委託至 bit888 微秒撮合引擎
    res = requests.post("https://api.bit888.com/v1/order", headers=headers, json={
        "symbol": symbol, "side": side, "type": "LIMIT", "price": price, "qty": amount
    })
    return res.json()
